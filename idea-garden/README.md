# 靈感種子 Idea Garden

一款手機優先的個人靈感孵化工具。可快速記錄想法、安排下一個小行動、追蹤生長階段並保留小勝利。

## GitHub Pages 上架

1. 在 GitHub 建立新的 repository，例如 `idea-garden`。
2. 將本資料夾內全部檔案上傳到 repository 最外層。
3. 進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/(root)`，按下 **Save**。
6. 稍候約 1–3 分鐘，GitHub 會顯示網站網址。

## 資料說明

- 靈感資料保存在使用中的瀏覽器 `localStorage`。
- 同一網址換到其他手機或電腦，資料不會自動同步。
- 右上角按鈕可下載 JSON 備份檔。
- 若清除瀏覽器網站資料，記錄也會被清除，請定期下載備份。

## 手機安裝

- Android Chrome：選單 →「加到主畫面」或「安裝應用程式」。
- iPhone Safari：分享 →「加入主畫面」。
